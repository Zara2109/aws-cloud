# 🚀 Introduction to Amazon EC2

## What is Amazon EC2?

Amazon Elastic Compute Cloud (Amazon EC2) is a web service provided by AWS that allows users to launch and manage virtual servers, known as **instances**, in the cloud.

Instead of purchasing and maintaining physical servers, EC2 enables users to rent computing resources on demand and pay only for what they use.

---

# Why Use EC2?

Amazon EC2 provides scalable, secure, and flexible computing capacity.

It is commonly used for:

- Hosting websites and web applications
- Running databases
- Deploying APIs
- Testing applications
- Development environments
- Cloud-based workloads

---

# Key Features

- Resizable virtual servers
- Multiple Operating Systems (Ubuntu, Amazon Linux, Windows, etc.)
- Pay-as-you-go pricing
- Secure access using SSH or RDP
- Integration with other AWS services
- Auto Scaling support
- Elastic IP support

---

# Components of an EC2 Instance

| Component | Description |
|-----------|-------------|
| AMI | Operating System Image used to launch the instance |
| Instance Type | CPU and RAM configuration |
| Key Pair | Used for secure SSH login |
| Security Group | Virtual firewall controlling inbound and outbound traffic |
| EBS Volume | Persistent storage attached to the instance |
| Public IP | Used to access the instance from the internet |
| Private IP | Used for communication inside the VPC |
